SEMSStudent Enrollment and Records
Platform technologies used
  • Supabase as the cloud service for the PostgreSQL database, authentication and hosted API
  • supabase-js as the SDK for sign in, queries and RPC calls from the browser
  • Supabase REST and RPC endpoints as the web service that carries enrollment, payment, approval and grading requests
  • JSON over HTTPS as the interoperability format between the page and the backend
  • Chart.js as a library for the admin dashboard charts
  • jsPDF as a library for the downloadable enrollment slip
  • DataTables with jQuery as a plug-in for searching, sorting and paging tables
  • Git and GitHub Pages for version control, collaboration and deployment
